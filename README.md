# AI 확인제 진행현황 위젯

AI 확인제(인공지능 제품·서비스 확인제도) 심사를 담당하면서, 공용 Google 스프레드시트의 "상태" 값만으로는 드러나지 않는 실무 진행 상황(일정 조율 중인지, 업체 회신을 기다리는 중인지, 증적자료를 주고받는 중인지, 내부 검토 단계인지 등)을 직접 추적하기 위해 만든 개인용 Windows 데스크톱 위젯입니다.

- Google 스프레드시트는 **읽기 전용**으로만 연동합니다.
- 실제 진행 상태·이력은 전부 로컬에 저장되며, 매 조회마다 history를 재생해 현재 상태를 계산합니다(상태를 직접 저장하지 않음).
- 담당 건마다 8단계 본 심사 흐름(사전 검토 → 일정 확정 → 심사 → 증적자료 → 내부 검토 → 적합 처리)과, 그와 별개로 발생하는 "신청서 보완"/"증적자료 요청" 같은 끼어드는 업무를 함께 추적합니다.

## 기술 스택

Electron + Svelte 5(runes) + TypeScript, `electron-vite`로 빌드, `electron-builder`로 Windows 패키징.

## 시작하기

### 1. 의존성 설치

```bash
npm install
```

### 2. Google OAuth 클라이언트 준비

[Google Cloud Console](https://console.cloud.google.com/)에서 OAuth 2.0 클라이언트 ID(데스크톱 앱)를 만들고, 다운로드한 JSON을 프로젝트 루트에 `credentials.json`으로 저장합니다. Sheets 읽기 권한(`spreadsheets.readonly`)만 있으면 됩니다.

### 3. 환경 설정 파일 생성

연동할 스프레드시트, 담당자명, 시트 헤더명을 본인 환경에 맞게 채웁니다.

```bash
cp src/main/config.example.ts src/main/config.ts
```

### 4. 개발 모드 실행

```bash
npm run dev
```

### 5. Windows 설치 파일 빌드

```bash
npm run build:win
```

`dist/win-unpacked/`에 실행 파일이, `dist/*-setup.exe`에 설치 파일이 생성됩니다.

## 사용법

### 1. 처음 실행하면

창 위쪽에 "Google 계정 연결이 필요합니다" 배너가 뜹니다. **연결하기**를 누르면 브라우저가 열리고 구글 로그인/동의 화면이 나옵니다. 동의하면 창으로 돌아와 자동으로 첫 동기화가 실행됩니다. 시트는 읽기 전용으로만 조회하며, 위젯은 시트에 아무것도 쓰지 않습니다.

### 2. 창 상단 아이콘

| 아이콘 | 기능 |
| --- | --- |
| ⟳ | 지금 바로 구글 시트와 동기화 (평소엔 매일 12:30, 서울 시간 기준으로 자동 동기화됩니다) |
| 📌 | 항상 위에 고정. 켜두면 다른 창으로 작업 중에도 위젯이 계속 보입니다. 기본값은 꺼짐 |
| ⚙ | 설정 패널 열기/닫기 |
| × | 창 숨기기(완전 종료 아님). 다시 보려면 트레이 아이콘을 클릭 |

### 3. 카드 한 장 읽는 법

- **제목**: 기업명 · 제품명
- **현재 상태 문구**: "증적자료 정리 중"처럼 지금 하고 있는 일을 가리키는 문구 (버튼 문구나 히스토리 기록 문구와는 별개입니다)
- **진행 단계 바**: 8단계 전체 흐름 중 어디까지 왔는지. 한 번 채워진 칸은 뒤로 되돌아가지 않습니다(일시적으로 전 단계로 돌아가는 경우가 있어도 바는 도달했던 최고 단계 기준으로 유지됩니다)
- **카드 배경색 = 지금 누구 차례인지**
  - 핑크(기본 팔레트 기준): 내가 다음 행동을 할 차례
  - 하늘색: 업체(신청 기업) 쪽 회신·조치를 기다리는 중
  - 보라색: 수석/팀장 검토가 진행 중이라 내가 당장 할 일은 없는 상태
  - 다른 색상 테마를 선택해도 세 가지 의미(내 차례 / 업체 차례 / 검토 차례) 자체는 동일하고, 배색만 바뀝니다
- **마감 임박 테두리**: 기준일(연장마감일이 있으면 그 날짜, 없으면 마감예정일)이 3일 이내로 남으면 카드 테두리에 붉은 강조선이 둘러집니다
- **배지**: 본 흐름과 별개로 진행 중인 "특수사항"이 있으면 카드 하단에 알약 모양으로 표시됩니다 (예: "신청서 보완 1차 대기", "증적자료 1차 처리중")

### 4. 본 심사 8단계 진행시키기

카드 왼쪽 아래 굵은 버튼이 본 흐름을 진행시키는 버튼입니다. 버튼 문구는 항상 "누르면 어떤 상태가 되는지"를 가리킵니다.

| 지금 상태 | 누르는 버튼 | 다음 상태 |
| --- | --- | --- |
| 사전 검토 중 | 사전검토 완료 | 일정 확정 중 |
| 일정 확정 중 | 일정 확정 | 심사 대기 중 |
| 심사 대기 중 | 심사 완료 | 심사 마무리 중 |
| 심사 마무리 중 | 증적자료 요청 | 증적자료 대기 중 |
| 증적자료 대기 중 | 증적자료 수령 | 증적자료 정리 중 |
| 증적자료 정리 중 | 수석 검토 요청 | 수석 검토 중 |
| 수석 검토 중 | 팀장 검토 요청 | 팀장 검토 중 |
| 팀장 검토 중 | 팀장 승인 | 적합 처리 중(적합 처리 대기) |

"적합 처리 중"으로 넘어간 뒤, 공용 시트의 상태가 실제로 "완료(적합)"로 바뀐 것을 동기화가 확인하면 카드가 자동으로 "완료(적합)" 상태가 됩니다 (§7 참고).

### 5. 멈춤 / 재개

**사전 검토 중 · 심사 대기 중 · 심사 마무리 중 · 증적자료 정리 중**, 이 네 단계에서는 업체 쪽 회신을 기다리는 특수사항(예: 신청서 보완 요청)을 열어두면 본 단계가 자동으로 "멈춤" 상태가 되고, 버튼 문구가 **"OO 재개"**로 바뀝니다. 재개를 누르면

1. 본 단계가 계속 진행되고,
2. 그 시점에 열려 있던 특수사항은 (수령까지 됐든 안 됐든) 전부 함께 종료되어 배지가 사라집니다.

재개 자체가 "더 이상 기다리지 않고 진행한다"는 의사결정이기 때문입니다. 반대로 **일정 확정 중 · 증적자료 대기 중**은 애초에 업체 응답을 기다리는 단계라 멈춤/재개 개념이 없고, 버튼은 항상 다음 단계로 바로 진행합니다. **수석 검토 중 · 팀장 검토 중** 두 단계는 내부 검토 중이라 특수사항 자체를 새로 열 수 없습니다.

### 6. 특수사항 (끼어드는 일)

본 흐름과 별개로 생기는 일은 **특수사항 ▾** 버튼의 드롭다운에서 처리합니다.

- **신청서 보완**: 요청 → (보완본 수령) → 보완 완료, 또는 다시 **재보완 요청**으로 차수를 늘려 반복할 수 있습니다. 완료(적합)/적합 처리 대기 중이거나 수석·팀장 검토 중일 때는 새로 열 수 없습니다.
- **증적자료 요청(별도)**: 본 흐름 3~5단계("증적자료 요청 → 수령 → 정리")와는 별개로, 그 전(사전 검토 중~심사 대기 중, 조기 요청) 또는 적합 처리 대기/완료 이후(사후 보완)에만 열 수 있는 추가 요청입니다. 흐름은 신청서 보완과 동일하게 요청 → 수령 → 정리완료 / 추가요청입니다.
- 메뉴를 열 때 하단 입력창에 메모를 적으면 해당 기록에 함께 남습니다.
- 차수(1차/2차…)는 버튼 문구에는 안 나타나고 카드 배지에만 "n차"로 표시됩니다.

"증적자료 정리 중" 단계에서는 특수사항 메뉴에 **증적자료 다시 요청**이 추가로 나타납니다 — 정리하다 자료가 더 필요해지면 이걸 눌러 "증적자료 대기 중"으로 되돌아갈 수 있습니다(진행 단계 바는 되돌아가지 않습니다).

### 7. 완료(적합) 처리

시트 상태가 "완료(적합)"으로 바뀐 것이 동기화되면 카드에 "완료(적합)으로 확정되었습니다. 목록에서 제외할까요?" 배너와 **목록에서 제외** 버튼이 나타납니다. 이 버튼을 직접 눌러야 카드가 목록에서 사라집니다(실수로 놓치는 걸 막기 위해 자동으로는 사라지지 않습니다).

### 8. 되돌리기 · 히스토리

- **↺**: 그 건에 가장 최근 기록된 동작 1건을 취소합니다. 여러 번 누르면 그만큼 거슬러 되돌릴 수 있습니다.
- **▼ / ▲**: 그 건의 전체 이력을 시간순으로 펼쳐보거나 접습니다.
- 펼친 히스토리에서 항목을 클릭하면 날짜와 메모를 수정하거나 그 기록을 삭제할 수 있습니다(잘못 누른 기록을 바로잡을 때 사용).

### 9. 트레이 아이콘

작업표시줄 구석의 트레이 아이콘을 좌클릭하면 창이 다시 보입니다. 우클릭하면 메뉴가 뜹니다: 보이기/숨기기, 지금 새로고침, 항상 위에 고정(체크 토글), 종료. **종료**를 눌러야 프로그램이 완전히 꺼지며, 창을 ×로 숨기기만 하면 트레이에는 계속 떠 있는 상태입니다.

### 10. 설정 (⚙)

- **PC 켤 때 자동 실행**: 컴퓨터를 켜면 위젯이 자동으로 함께 실행됩니다. (설치된 앱 기준으로만 동작하며 `npm run dev` 개발 모드에서는 켜도 효과가 없습니다.)
- **색상 테마**: 기본(핑크·블루·퍼플) 외 오션 · 민트 · 스카이 · 더스크 · 로즈 중에서 선택할 수 있습니다. 바로 적용되고, 다음에 실행해도 선택한 테마가 유지됩니다.

## 테스트

핵심 상태 도출 로직(`src/main/data/derive.ts`)과 시트 동기화 로직(`src/main/sync/syncService.ts`)은 Node 내장 테스트 러너로 검증합니다.

```bash
node --test src/main/data/derive.test.ts src/main/sync/syncService.test.ts
```

## 로컬 데이터 위치

실행 중 쌓이는 진행 이력·설정값은 소스 트리와 분리되어 `%APPDATA%/ai-hwakinje-widget/`에 저장됩니다 (`products.json` + 백업, `config.json`, `token.json`).
